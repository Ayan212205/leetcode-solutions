This repository contains my solutions to problems solved on [LeetCode](https://leetcode.com/).

I use this repository to track my progress in Data Structures and Algorithms, improve problem-solving skills, and prepare for technical interviews.

- Arrays
- Strings
- Hashing
- Two Pointers
- Sliding Window
- Prefix Sum
- Recursion
- Linked Lists
- Sorting

- Stack & Queue
- Trees
- Graphs
- Dynamic Programming

More topics will be added as I progress.

## 💻 Language

- Java

## 📊 Progress

I regularly solve LeetCode problems and push my accepted solutions to this repository.

- Time and space complexity
- Why the solution works
